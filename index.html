Quarks-JS

A dependency-free WebGL particle background: linked “quarks,” electric-style connections, mouse grab/attract, lifelike wander + flocking, and an evolve mode where boids eat, grow, and predators can attack each other.

How to use

  1. Drop in a canvas, load config.js then webgl-quarks.js.
  2. Call initQuarksWebGL(canvasId, config) on DOM ready.
  3. Move the cursor to grab/attract particles; mark blockers with .quark-obstacle.
  4. Tune live below, or edit defaults in js/config.js.
